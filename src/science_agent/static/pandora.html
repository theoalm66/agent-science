Literature search

i Without a key Semantic Scholar often answers “429 Too Many Requests” and only arXiv results are used. A free key: semanticscholar.org/product/api

Settings and keys are stored only in this browser (localStorage). Keys are sent to the local Pandora server with each run, which uses them in memory for the calls to your endpoint and never writes them to disk or to reports. Defaults come from config.yaml.

Backup & transfer

Save runs, prompt and skill versions and the connection settings as one JSON file, to keep a backup or move everything to another computer. Importing merges: nothing is overwritten, duplicates are skipped, and imported prompt/skill versions are added to the history without being activated.

With “include API keys” the file contains them in plain text. Do not share such a file.
